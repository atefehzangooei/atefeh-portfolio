## <font color="#00CFCF">01 / ABOUT THE PROJECT</font>

### درباره پروژه

نیمدری یک پلتفرم آنلاین آگهی است که با هدف ایجاد بستری ساده و کاربردی برای معرفی کالاها، محصولات و خدمات توسعه داده شده است.

کاربران می‌توانند آگهی‌های موردنظر خود را جست‌وجو کنند، آگهی جدید ثبت کنند، فروشگاه خود را مدیریت کنند و از طریق امکانات ارتباطی اپلیکیشن با سایر کاربران در ارتباط باشند.

این محصول از یک اپلیکیشن Android و یک Backend مستقل تشکیل شده که از طریق REST API با یکدیگر ارتباط دارند.
