## درباره پروژه

نیمدری یک پلتفرم آنلاین برای ثبت، جست‌وجو و مدیریت آگهی‌های کاربران است. این اپلیکیشن بستری برای معرفی کالاها و خدمات، ارتباط میان کاربران و مدیریت آگهی‌ها فراهم می‌کند.

این محصول شامل یک اپلیکیشن Android و یک Backend مستقل است که از طریق REST API با یکدیگر ارتباط دارند.

## امکانات و قابلیت‌ها

| قابلیت | توضیحات |
|---|---|
| احراز هویت | ورود و ثبت‌نام با شماره موبایل و OTP |
| مدیریت آگهی | ثبت، ویرایش، حذف و مشاهده آگهی‌ها |
| دسته‌بندی | دسته‌بندی چندسطحی و انتخاب ویژگی‌های آگهی |
| جست‌وجو | جست‌وجو و فیلتر بر اساس شهر، قیمت و دسته‌بندی |
| موقعیت مکانی | انتخاب شهر و محدوده انتشار آگهی |
| مدیریت تصاویر | بارگذاری تصاویر آگهی |
| ارتباط کاربران | چت درون‌برنامه‌ای، تماس و WhatsApp |
| علاقه‌مندی‌ها | ذخیره آگهی‌ها و ثبت یادداشت |
| مدیریت فروشگاه | ایجاد فروشگاه و مدیریت محصولات |
| پرداخت | کیف پول، سوابق پرداخت و ارتقای آگهی |
| گزارش‌ها | مشاهده آمار بازدید و گزارش تخلف |

## مسئولیت‌های من

توسعه Full-Stack پروژه، شامل:

- طراحی و توسعه اپلیکیشن Android با Java و XML
- پیاده‌سازی رابط کاربری و جریان‌های اصلی اپلیکیشن
- توسعه Backend با PHP و Laravel
- پیاده‌سازی ارتباط اپلیکیشن و سرور از طریق REST API
- پیاده‌سازی قابلیت‌های ثبت، جست‌وجو و مدیریت آگهی‌ها
- پیاده‌سازی امکانات ارتباطی و پرداخت
- کار با پایگاه داده MySQL

- پیاده‌سازی سیستم چت و مدیریت مکالمات کاربران

- یکپارچه‌سازی امکانات پرداخت و ارتقای آگهی
