## معرفی پروژه

**کالرا (Calera)** یک اپلیکیشن هوشمند مدیریت تغذیه و کالری است که با هدف کمک به کاربران برای کنترل دریافت انرژی روزانه، مدیریت درشت‌مغذی‌ها و انتخاب آگاهانه‌تر وعده‌های غذایی توسعه داده شده است.

این اپلیکیشن با ترکیب قابلیت‌های مدیریت تغذیه، تحلیل هوشمند غذا با استفاده از هوش مصنوعی و تولید رسپی‌های متناسب با اهداف تغذیه‌ای کاربر، تجربه‌ای فراتر از یک کالری‌شمار معمولی ارائه می‌دهد.

کالرا از یک اپلیکیشن اندرویدی بومی و یک بک‌اند اختصاصی تشکیل شده است. پردازش اطلاعات، مدیریت کاربران، ارتباط با سرویس هوش مصنوعی، کنترل مصرف اعتبار و مدیریت تراکنش‌های مالی در سمت سرور انجام می‌شوند.

توسعه کامل اپلیکیشن اندروید و بک‌اند پروژه به‌صورت مستقل انجام شده است.

## امکانات و قابلیت‌ها

### ۱. داشبورد مدیریت تغذیه روزانه

داشبورد اصلی کالرا با هدف نمایش یکپارچه وضعیت تغذیه کاربر در طول روز طراحی شده است.

امکانات این بخش:

- نمایش میزان کالری موردنیاز روزانه.
- نمایش کالری مصرف‌شده و کالری باقی‌مانده.
- نمایش میزان مصرف درشت‌مغذی‌ها شامل پروتئین، کربوهیدرات و چربی.
- مقایسه مقادیر مصرف‌شده با اهداف تغذیه‌ای روزانه.
- نمایش وضعیت وعده‌های غذایی ثبت‌شده.
- مشاهده و مدیریت اطلاعات تغذیه در روزهای مختلف.
- انتخاب تاریخ با استفاده از تقویم شمسی.
- امکان جابه‌جایی بین روزهای مختلف در بازه ۳۰ روزه.

### ۲. ثبت و مدیریت وعده‌های غذایی

کاربران می‌توانند وعده‌های غذایی روزانه خود را در دسته‌بندی‌های مختلف ثبت و مدیریت کنند.

دسته‌بندی وعده‌ها:

- صبحانه
- ناهار
- شام
- میان‌وعده

اطلاعات تغذیه‌ای غذاهای ثبت‌شده در محاسبات روزانه لحاظ می‌شود تا کاربر بتواند وضعیت کالری و درشت‌مغذی‌های مصرفی خود را دنبال کند.

### ۳. تحلیل هوشمند غذا با هوش مصنوعی

یکی از قابلیت‌های اصلی کالرا، امکان تحلیل وعده‌های غذایی با استفاده از هوش مصنوعی است.

کاربر می‌تواند نام یا توضیحات غذای مصرف‌شده را به زبان طبیعی وارد کند و اطلاعات تغذیه‌ای آن را دریافت کند.

مراحل پردازش:

۱. انتخاب نوع وعده غذایی.

۲. وارد کردن توضیحات غذا توسط کاربر.

۳. ارسال درخواست به بک‌اند اختصاصی.

۴. پردازش درخواست و ارتباط بک‌اند با سرویس هوش مصنوعی.

۵. دریافت و پردازش پاسخ ساختاریافته هوش مصنوعی.

۶. نمایش اطلاعات تغذیه‌ای استخراج‌شده به کاربر.

۷. بررسی و تأیید اطلاعات توسط کاربر.

اطلاعات قابل استخراج شامل:

- نام غذا
- میزان کالری
- پروتئین
- کربوهیدرات
- چربی

این قابلیت با هدف ساده‌سازی فرایند ثبت غذا و کاهش نیاز به محاسبات دستی طراحی شده است.

### ۴. تولید رسپی هوشمند و شخصی‌سازی‌شده

کالرا از یک سیستم پیشنهاد و تولید رسپی مبتنی بر هوش مصنوعی بهره می‌برد که پیشنهادهای غذایی را با توجه به وضعیت تغذیه‌ای و اهداف کاربر تولید می‌کند.

کاربر می‌تواند با انتخاب نیاز یا هدف تغذیه‌ای خود، پیشنهادهای متناسب دریافت کند.

نمونه اهداف و درخواست‌ها:

- نیاز به پروتئین بیشتر
- دریافت غذای کم‌کالری
- انتخاب غذا متناسب با نیاز تغذیه‌ای روزانه

اطلاعات مورد استفاده در فرایند تولید رسپی:

- هدف کالری روزانه
- کالری مصرف‌شده
- کالری باقی‌مانده
- هدف پروتئین
- پروتئین مصرف‌شده و باقی‌مانده
- هدف چربی
- چربی مصرف‌شده و باقی‌مانده
- هدف کربوهیدرات
- کربوهیدرات مصرف‌شده و باقی‌مانده

اطلاعات هر رسپی تولیدشده می‌تواند شامل موارد زیر باشد:

- عنوان غذا
- دسته‌بندی غذا
- دستور پخت
- زمان آماده‌سازی
- زمان پخت
- اطلاعات تغذیه‌ای
- نکات تکمیلی پخت

هدف این سیستم، ارائه پیشنهادهایی است که علاوه بر تنوع غذایی، با نیازهای تغذیه‌ای کاربر نیز هماهنگ باشند.

### ۵. مدیریت پروفایل و اهداف تغذیه‌ای

اطلاعات پروفایل کاربر و اهداف تغذیه‌ای در محاسبات و پیشنهادهای هوشمند اپلیکیشن مورد استفاده قرار می‌گیرند.

قابلیت‌های این بخش:

- مدیریت اطلاعات پروفایل.
- ثبت مشخصات موردنیاز برای محاسبات تغذیه‌ای.
- تعیین اهداف کالری روزانه.
- تعیین اهداف درشت‌مغذی‌ها.
- استفاده از اطلاعات شخصی برای ارائه پیشنهادهای تغذیه‌ای متناسب.

### ۶. احراز هویت و مدیریت نشست کاربران

سیستم احراز هویت کالرا بر اساس شماره تلفن همراه و کد یک‌بارمصرف (OTP) طراحی شده است.

مراحل ورود و احراز هویت:

۱. دریافت شماره تلفن همراه.

۲. درخواست ارسال کد تأیید.

۳. ارسال کد یک‌بارمصرف از طریق پیامک.

۴. اعتبارسنجی کد واردشده.

۵. احراز هویت کاربر و ایجاد نشست کاربری.

قابلیت‌های امنیتی و مدیریتی:

- احراز هویت با شماره تلفن همراه.
- ارسال و اعتبارسنجی کد یک‌بارمصرف.
- مدیریت Access Token و Refresh Token.
- تمدید خودکار توکن دسترسی.
- مدیریت وضعیت نشست کاربر.
- ذخیره‌سازی امن اطلاعات احراز هویت در دستگاه.
- مدیریت وضعیت تکمیل پروفایل کاربر.
- مدیریت خروج از حساب کاربری.

### ۷. مدیریت اعتبار و خرید درون‌برنامه‌ای

برای مدیریت استفاده از قابلیت‌های هوش مصنوعی، سیستم اعتبار (Credit) در کالرا پیاده‌سازی شده است.

امکانات این سیستم:

- اختصاص سهمیه رایگان روزانه برای استفاده از هوش مصنوعی.
- ارائه ۷ درخواست رایگان در هر روز.
- مدیریت اعتبار خریداری‌شده.
- کسر اعتبار پس از پردازش موفق درخواست هوش مصنوعی.
- خرید اعتبار از طریق پرداخت درون‌برنامه‌ای کافه‌بازار.
- اعتبارسنجی توکن خرید از طریق سرور.
- جلوگیری از ثبت و اعمال مجدد خرید تکراری.
- ثبت سوابق تراکنش‌ها.
- مدیریت وضعیت پرداخت و اعتباردهی.

اعتباردهی پس از تأیید خرید توسط سرویس پرداخت و اعتبارسنجی سمت سرور انجام می‌شود.

## معماری و ساختار فنی

کالرا بر اساس معماری Client-Server توسعه داده شده است.

اپلیکیشن اندروید از طریق APIهای مبتنی بر REST با بک‌اند اختصاصی ارتباط برقرار می‌کند.

بک‌اند مسئول مدیریت منطق اصلی برنامه، پردازش اطلاعات، ارتباط با سرویس‌های خارجی و عملیات پایگاه داده است.

### ساختار کلی ارتباط اجزای سیستم

```text
       Android Application
       Kotlin + Jetpack Compose
                 |
                 |
             REST API
                 |
                 v
       Spring Boot Backend
                 |
       +---------+----------+
       |         |          |
       v         v          v
   PostgreSQL   AI API    SMS Service
       |
       |
       v
   User Data
   Nutrition
   Recipes
   Transactions

       Cafe Bazaar
            |
            v
      Payment Validation
```
