# سلام، من عاطفه هستم 👋

### توسعه‌دهنده Full-Stack Android

توسعه‌دهنده نرم‌افزار با تمرکز بر طراحی و توسعه اپلیکیشن‌های Android و پیاده‌سازی سرویس‌های Backend.

علاقه‌مند به ساخت محصولات نرم‌افزاری کاربردی، حل مسائل پیچیده فنی و توسعه سیستم‌های ساختارمند، پایدار و قابل نگهداری.

## 👩🏻‍💻 درباره من

من یک توسعه‌دهنده نرم‌افزار با تجربه در توسعه اپلیکیشن‌های Android و سرویس‌های سمت سرور هستم.

مسیر برنامه‌نویسی من از زبان‌های مختلفی مانند C++، C# و Java آغاز شده و در ادامه به توسعه اپلیکیشن‌های Android با Java و Kotlin و پیاده‌سازی Backend رسیده است.

زمینه‌های اصلی فعالیت من:

- توسعه اپلیکیشن‌های Native Android
- طراحی و پیاده‌سازی رابط کاربری با Jetpack Compose و XML
- توسعه سرویس‌های Backend با Kotlin و Spring Boot
- طراحی و پیاده‌سازی REST API
- ارتباط با پایگاه داده و مدیریت اطلاعات
- پیاده‌سازی سیستم‌های احراز هویت و مدیریت نشست کاربران
